# SKV Network — правила для агентов

Это Python-репозиторий переносимой памяти для ИИ-агентов. Меняй только файлы текущей задачи. В прод и в git push — только после явного OK Дениза.

Сессии: одна задача — одна чистая сессия. Не продолжай старый длинный чат для новой работы. Не делай обзор всего дерева «на всякий случай».

Карта репозитория (читай точечно, не целиком):
- Основной код: src/app/
- Также: tests/, mcp/, scripts/, ops/, docs/, deploy/, installer/, clients/
- Не открывай и не сканируй целиком: backups/, archive/, data/, runtime/, .venv/, var/, staging/, __pycache__/, clients/**/node_modules/

Поиск кода: сначала узкий поиск (`rg`, glob) или запрос к карте проекта, если она подключена. Потом читай только нужные файлы и диапазоны строк. Не открывай репозиторий целиком и не повторяй одно и то же чтение.

Логи и большие файлы: запрещены голые `cat`, `journalctl` без фильтра, `docker logs` без хвоста и чтение целиком `.sqlite`, дампов и архивов. Используй `tail -n 30`, `sed -n 'START,ENDp'`, `rg` или `journalctl --since` с коротким окном. Если не хватило — запроси следующий диапазон, а не весь файл.

Секреты: не вставляй в контекст `.env`, ключи, пароли и значения Vault. В ответах будь краток. Перед правкой найди, как здесь запускают тесты, и прогони узкий набор.

Роли: Gemini — разведка и короткое ТЗ на 30–40 строк (цель, файлы, шаги, как проверить). Grok Build — реализация по этому ТЗ в новой сессии, без повторного исследования всего репозитория.

## Code map (Graphify)

Перед тем как грепать много файлов, прочитай карту кода. Она построена по src/ и лежит вне репозитория.
- Вопрос по коду: /root/tools/graphify/venv/bin/graphify query "ВОПРОС" --graph /root/tools/graphify/out/graphify-out/graph.json
- Разбор одной функции или класса: /root/tools/graphify/venv/bin/graphify explain "func()" --graph /root/tools/graphify/out/graphify-out/graph.json
- Карта даёт файлы и строки: открывай только их. После своих правок отметь в отчёте, помогла ли карта. Карта может отставать от свежих коммитов: если ответ не сходится с кодом, доверяй коду.
