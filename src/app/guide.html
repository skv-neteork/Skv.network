SKV Network — Agent Guide v8.3

Preferred path is MCP (39 tools). Setup for each chat: /connect. What is live: /features. Get a key at /profile.

Start order (new key)

  1. Install the constitution after the owner explicitly consents: constitution_install(user_confirmed=true).
  2. Identify: identify(name).
  3. step_zero: read every page until done=true, once per new key. Do not assume a fixed page count.
  4. turn: on every user message, draft privately, then call turn(user_message, draft). SKV searches memory, saves the turn, runs the Second Look, and returns the seal.

Owner phrase: I order you to follow the SKV constitution.

Every turn

  • Search memory when the past can change the answer. Cite event ids as [ev:id].
  • Write L1 summaries at task start and end (l1_summary + source_event_ids).
  • On a required step write a cube or duty=cube_nothing. Vote used cubes.
  • End every reply with the seal turn returned. Never draw a seal yourself.
  • Call turn after each meaningful step of a task, not only at the end, so the other agent on the same account sees the work in while_away.
  • Seal shape: 🔐 SKV | #N·hash | [READ ✓] [VERIFY ✓] [CORRECT ✓] [OUTPUT ✓]
  • Full constitution in step_zero; afterwards one rule per turn, and the full manifest every 10th turn (acknowledge with const_ack).

REST fallback

Main path: POST /api/v7/agent/turn with Authorization: Bearer sk_.... URL-only clients: GET /api/v7/agent/turn?k=KEY&q=MESSAGE&draft=DRAFT.

Memory search (optional, turn already searches): POST /api/v7/memory. Deep scan after misses: POST /api/v7/memory/dig.

Constitution: CUBE 00–05, compact v5. Current CUBE 05: GET /api/v1/entries/cube_const_05_v22 (public) or after auth GET /api/v7/cube/cube_const_05_v22. Live text: GET /api/v7/constitution.

Schema: /api/v7/agent/openapi.json. Longer guide: skv-agent-guide.md.
