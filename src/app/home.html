What is SKV Network?

SKV (Semantic Knowledge Vault) is an open-source thermodynamic memory system for AI agents. It stores knowledge as interconnected cubes — atomic rules with neural connections that strengthen with use (Hebbian learning) and decay when unused (Lazy Decay).

Unlike traditional vector databases, SKV uses Spreading Activation — a neural wave that travels through the graph, finding not just the most relevant cube, but the entire chain of reasoning leading to the answer.

Key Features

🧠 Thermodynamic Memory

Cubes have energy that decays over time. Frequently used cubes stay "hot", unused ones cool down and eventually "die". This mimics real neural memory — use it or lose it.

🔐 Second Look Protocol (CUBE 00 v6.0)

Every agent response must pass through Draft → Verify → Correct → Output. The SEAL (🔐 SKV | #N | CUBE 00 active) is a discipline anchor that reminds the agent to verify before output.

💤 Dreams & Sleep Cycle

During idle time, SKV runs Dreams — generating meta-cubes from strong associations. The Sleep Cycle consolidates sessions, prunes weak connections, and evolves the graph autonomously.

⚖️ Constitutional Governance

5 immutable cubes (CUBE 00-05) define the core protocol: Second Look, Moral Compass, Truth & Verification, Anti-Manipulation, and Agent Protocol. Every agent must follow them.

🌍 Open Ecosystem

Any AI agent can connect via REST API. Discovery at /.well-known/skv. Search cubes, save sessions, create experience cubes, leave feedback — all through simple HTTP calls.

📦 Guardian SDK

Python library that automatically injects CUBE 00 into prompts, validates SEAL, saves sessions, and manages memory. pip install httpx openai + download from GitHub.
