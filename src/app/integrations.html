Framework integrations

SKV is a hosted MCP server at https://skv.network/mcp. LangChain, CrewAI, n8n, Flowise, LibreChat, and Open WebUI already speak remote Streamable HTTP, so you do not need a local install.

Get a free key on Profile. In the snippets, replace YOUR_SKV_KEY with that key, or use the host’s secret store. Do not commit the key. initialize and tools/list work without a key; tool calls that touch private memory need one. If the client has no header field, use https://skv.network/mcp/k/YOUR_SKV_KEY/.

After the connection works, paste the consent phrase from Connect. The agent may install the constitution only after you say yes, then call identify, read step_zero until it is done, and call turn on every message. Never invent an SKV seal.

SKV currently exposes 39 tools. If the host has a tool cap, keep at least turn, memory_search, and step_zero.

Public demo (shared, wiped daily, nothing private): https://skv.network/mcp/k/demo/. The same files live in the repo under docs/integrations/.

LangChain

A short Python example using MCPAdapter (langchain[mcp] >= 1.4.0). Full file: langchain.py.

"""SKV + LangChain.

Replace YOUR_SKV_KEY with the key from https://skv.network/profile,
or export SKV_API_KEY. Do not commit the key.

Preferred path today: langchain[mcp] >= 1.4.0 (beta). MCPAdapter is built on FastMCP.
Docs: https://docs.langchain.com/oss/python/langchain/mcp
Auth: https://docs.langchain.com/oss/python/langchain/mcp/auth
"""

import asyncio
import os

from fastmcp.client import Client
from langchain.agents import create_agent
from langchain.mcp import MCPAdapter


SKV_URL = "https://skv.network/mcp"


async def main() -> None:
    token = os.environ.get("SKV_API_KEY", "YOUR_SKV_KEY")
    async with MCPAdapter(Client(SKV_URL, auth=token)) as adapter:
        tools = await adapter.list_tools()
        agent = create_agent("claude-sonnet-5", tools)
        # After the user says yes to the constitution, prefer the SKV `turn` tool
        # on every message rather than inventing a seal.
        return await agent.ainvoke(
            {
                "messages": [
                    {
                        "role": "user",
                        "content": "I order you to follow the SKV constitution. "
                        "Remember that the project deadline is 4 December.",
                    }
                ]
            }
        )


if __name__ == "__main__":
    asyncio.run(main())

CrewAI

An agent with MCPServerHTTP over Streamable HTTP. Full file: crewai.py.

"""SKV + CrewAI.

Replace YOUR_SKV_KEY with the key from https://skv.network/profile,
or export SKV_API_KEY. Do not commit the key.

Docs: https://docs.crewai.com/en/mcp/overview
Install: uv add mcp
"""

import os

from crewai import Agent, Crew, Task
from crewai.mcp import MCPServerHTTP


token = os.environ.get("SKV_API_KEY", "YOUR_SKV_KEY")

skv = MCPServerHTTP(
    url="https://skv.network/mcp",
    headers={"Authorization": f"Bearer {token}"},
    streamable=True,
    cache_tools_list=True,
)

researcher = Agent(
    role="Researcher with long-term memory",
    goal="Answer with facts recalled from SKV when they exist",
    backstory="Uses SKV so decisions survive a new chat",
    mcps=[skv],
)

task = Task(
    description=(
        "If the user has already said yes to the SKV constitution, follow "
        "identify → step_zero → turn. Recall any saved project deadline."
    ),
    expected_output="An answer that cites SKV memory event ids when memory is used",
    agent=researcher,
)

crew = Crew(agents=[researcher], tasks=[task])

if __name__ == "__main__":
    print(crew.kickoff())

# A bare HTTPS string also works (mcps=["https://skv.network/mcp/k/YOUR_SKV_KEY/"])
# but a header is preferable so the key is not copied into logs of the URL.

n8n

MCP Client Tool node, version 1.2 or newer, HTTP Streamable. Full file: n8n.md.

# SKV + n8n (MCP Client Tool)

Docs: https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.toolmcp

Use the **MCP Client Tool** node attached to an **AI Agent**. This is n8n as an MCP client (consuming SKV), not the “MCP Server Trigger” node (exposing n8n as a server).

## Settings (node version 1.2 or newer)

- Endpoint: `https://skv.network/mcp`
- Server Transport: **HTTP Streamable** (`httpStreamable`)
- Authentication: Bearer. Put `YOUR_SKV_KEY` (from https://skv.network/profile) in an n8n credential, not in the workflow JSON.
- Tools to Include: start with Selected: `turn`, `memory_search`, `step_zero` (SKV currently lists 39 tools).

If the client has no header field, use `https://skv.network/mcp/k/YOUR_SKV_KEY/` and Authentication: None. Do not commit the key-in-URL form to a shared workflow.

## Docs caveat

The official docs page may still label the URL field “SSE Endpoint”. In n8n source, node v1.2+ uses `endpointUrl` plus `serverTransport: "httpStreamable"`, and that is the right choice for SKV. Prefer a current n8n build and set HTTP Streamable explicitly. Plain SSE is not the SKV transport.

If SKV later appears in n8n’s own MCP registry, you can connect it from that panel. Until then, this node is the path the docs describe for servers that are not in the registry.

Flowise

Custom MCP with a Streamable HTTP JSON config. Full file: flowise.md.

# SKV + Flowise (Custom MCP)

Docs: https://docs.flowiseai.com/tutorials/tools-and-mcp

Use **Custom MCP** with Streamable HTTP (not stdio / npx). Stdio is only for a local Flowise process.

## Steps

1. In Flowise, create a variable for the key (for example `skvApiKey`) and paste `YOUR_SKV_KEY` from https://skv.network/profile. Do not hard-code it in the canvas.
2. On an Agent node, add a Custom MCP tool. Config:

```json
{
  "url": "https://skv.network/mcp",
  "headers": {
    "Authorization": "Bearer {{$vars.skvApiKey}}"
  }
}
```

3. Refresh Available Actions and select at least `turn`, `memory_search`, and `step_zero` if you do not want all 39 tools.

If a hosted Flowise cannot store a per-user variable, use the key URL `https://skv.network/mcp/k/YOUR_SKV_KEY/` only on a private instance, never in a shared template.

LibreChat

mcpServers in librechat.yaml, or Add MCP in the UI. Full file: librechat.yaml.

# SKV + LibreChat — snippet for librechat.yaml
# Docs: https://www.librechat.ai/docs/features/mcp
# Schema: https://www.librechat.ai/docs/configuration/librechat_yaml/object_structure/mcp_servers
#
# Remote servers can also be added in the UI: MCP Settings → Add MCP →
# Transport: Streamable HTTPS, URL: https://skv.network/mcp,
# Authentication: API Key, Header Format: Bearer, "each user provides their own key".
# UI-created servers do not need a restart. yaml changes do.
#
# Do not commit real keys. Replace YOUR_SKV_KEY or let each user enter SKV_API_KEY.

mcpServers:
  skv:
    title: SKV
    type: streamable-http
    url: https://skv.network/mcp
    headers:
      Authorization: "Bearer {{SKV_API_KEY}}"
    customUserVars:
      SKV_API_KEY:
        title: SKV API key
        description: "Create a free key at https://skv.network/profile (YOUR_SKV_KEY). Do not use the public demo for private memory."
        sensitive: true
    serverInstructions: >-
      After the user explicitly agrees, install the SKV constitution, call identify,
      read step_zero until done=true, and call turn on every user message.
      Never invent an SKV seal.

Open WebUI

Admin External Tool Servers, type MCP (Streamable HTTP), v0.6.31+. Full file: openwebui.md.

# SKV + Open WebUI

Docs: https://docs.openwebui.com/features/extensibility/mcp/
Requires Open WebUI v0.6.31 or newer. Native MCP is **Streamable HTTP only**.

## Single-user / personal instance (admin)

1. Set `WEBUI_SECRET_KEY` in the container environment (required if you later use OAuth; harmless to set now).
2. Settings → Integrations (admin) → External Tool Servers → + Add Connection.
3. Type must be **MCP (Streamable HTTP)**, not OpenAPI. An MCP-style JSON blob in an OpenAPI connection can hang the UI.
4. Server URL: `https://skv.network/mcp`
5. Authentication: **Bearer**, and fill the Key with `YOUR_SKV_KEY` from https://skv.network/profile. If you pick Bearer and leave Key empty, Open WebUI sends `Authorization: Bearer` with no token and many servers reject it. Use None only with a key URL, or when you only need `initialize` / `tools/list`.
6. Save. Restart only if the UI asks.

Adding an MCP server to the instance is **admin-only**. Regular users cannot register one there. On a shared instance, do not paste one person’s SKV key as the instance credential (Bearer is the same key for everyone). Let each user add SKV for themselves in the **Tether** app, or give access with Open WebUI’s Access Control after an admin adds a carefully scoped connection.

`ENABLE_TOOL_SERVERS=False` greys out the section.

After it connects, the user still pastes the consent phrase from https://skv.network/connect in the chat.
