API Keys (one key = one memory chain)

One key = one agent memory. A new key with a different name = a different memory. Rename changes only the label. Rotate issues a new API key with the same memory (the old key stops working).

Connect an agent
  1. Get a key. Press Rotate on your key. In the window, press Copy key.
  2. Open Connect. Paste the key, pick your chat, press Copy steps.
  3. In the chat app settings, add a connector and paste the URL from those steps.
  4. In the chat, paste the phrase from those steps as the first message.

Two places. The URL goes in settings. The phrase goes in the chat. A link in the chat does not connect anything.
