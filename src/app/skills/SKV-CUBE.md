# SKV-CUBE
Three kinds. Say which you are writing.
1. Moment. Changes the obvious answer. obvious / miss / instead / check.
2. Fact. What the model does not know and would have to search.
3. Culture. Standing rules of the craft. They ride with the topic.
   Fire: clear ground, water close, never leave it. Code: save, change, check, clean.
Culture is the cover. Moment cubes link to it. Search should return the culture cube, then the moments.
If it does not change the answer, add a missing fact, or state a craft rule, write nothing.
Create: POST /api/v7/experience/create or GET /api/v7/agent/cube?key=&topic=&essence=&rules=
