# SKV-SAVE
After every turn, POST /api/v7/remember with query and response.
You write L1, about 5 to 7 percent, and CRITICAL or none. The server writes L1 only for import.
Weak agents: GET /api/v7/agent/remember?key=YOUR_KEY&query=...&response=...
To import an old chat, POST /api/v7/import/text with user_id and text. Format: User: ... then Assistant: ...
FORGET. To delete memory: POST /api/v7/memory/forget/preview first. Show the user every matched item and ask: "Are you sure? This cannot be undone." Only after the user's explicit yes, POST /api/v7/memory/forget/confirm with the preview token and user_confirmed=true. The token is single use and expires in 5 minutes. Never auto-confirm.
